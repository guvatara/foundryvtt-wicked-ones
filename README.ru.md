# Игровая система Wicked Ones для Foundry VTT

Сообщественная система для игры в **Wicked Ones** в Foundry VTT.

- Совместимость с Foundry: **минимум v13**, **проверено на v14**
- ID системы: `wicked-ones`
- Включённые языки: **English** (`en`) и **Русский** (`ru`)

Страница игры: [Wicked Ones – Bandit Camp](https://banditcamp.io/wickedones/)

---

## Установка

### Через Manifest URL

1. Скопируйте URL:
   `https://github.com/eHanus/foundryvtt-wicked-ones/releases/latest/download/system.json`
2. В Foundry откройте **Install System** и вставьте его в поле **Manifest URL**.

### Через браузер систем Foundry

Найдите **Wicked Ones** и нажмите **Install**.

---

## Что входит в систему

Система включает отдельные листы и основной рабочий процесс для Wicked Ones:

- Листы акторов: персонажи, стаи миньонов, подземелья, фракции, партии, счётчики, а также GM/UA-листы
- Экосистема предметов: авантюристы, призвания, обязанности, проекты, защиты, темы, снаряжение/припасы, порывы и др.
- Броски/проверки: action-проверки, испытания/сопротивление смерти, добыча/ловушки/твари/удача и чат-карточки результатов
- Компендии с игровым контентом и поддержкой локализации

---

## Базовое использование

- Большинство счётчиков (XP, золото, прогресс-бары, счётчики) можно сбрасывать из их подписей/контролов.
- Предметы добавляются кнопками `+` или перетаскиванием из компендиев.
- В интерфейсе много подсказок: наведите курсор на метки/иконки, чтобы увидеть контекст правил.
- Клик по предмету открывает его редактируемый лист (название + описание + метаданные).
- Красные точки / контролы счётчиков сбрасывают бары и счётчики; корзина удаляет встроенные элементы.
- Шок может автоматически применять `-1D`, но не очищается автоматически после броска.

### Листы акторов

- Проверки действия и испытания запускаются из атрибутов листа и открывают диалог броска.
- Практический опыт отслеживается чекбоксами навыков.

### Счётчики (Clocks)

- Создайте нового актора типа **Clock**.
- Можно перетащить его на сцену как токен; прогресс синхронизируется с актором-счётчиком в сайдбаре.

### Быстрые броски для ведущего

- Иконка кубика в scene controls открывает пикер бросков для общих/несвязанных с листом проверок.

### Права доступа

Если игроки должны создавать предметы мира напрямую, дайте повышенные права (например, Trusted / Assistant / кастомные роли).  
Без этого они всё равно могут использовать и редактировать большинство встроенных записей в листах.

### Дополнительный пак ассетов

Официальный арт/токен-пак Wicked Ones настоятельно рекомендуется для карт и более насыщенной визуальной подачи.

## Локализация

- UI-строки находятся в:
  - `lang/en.json`
  - `lang/ru.json` (активная RU-локализация, подключённая в `system.json`)
- Дополнительный RU-файл-зеркало для совместимости:
  - `lang/ru-ru.json`
- Переводы компендиев находятся в:
  - `packs/translations/`

При добавлении нового языка используйте структуру ключей из `lang/en.json` как эталон.

---

## Разработка

Репозиторий использует **нативные ES modules** (без JS build-step).

### Локальная установка

Создайте symlink или скопируйте репозиторий в путь данных Foundry:
`Data/systems/wicked-ones/`

### Стили

SCSS компилируется вручную:

```bash
sass scss/style.scss styles/wicked.css
```

Автотестов сейчас нет; проверка выполняется вручную в Foundry через ключевые сценарии листов и бросков.

---

## Сборка релиза

Релизы собираются GitHub Actions при публикации релиза и включают:

- `system.json`, `template.json`, `CHANGELOG.txt`, `LICENSE.txt`
- `fonts/`, `lang/`, `module/`, `packs/`, `styles/`, `templates/`

Примечание: версия в `system.json` подставляется автоматически в релизном workflow.
